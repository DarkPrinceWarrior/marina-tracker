# Ритм (Marina Tracker)

Персональный мобильный PWA-трекер для **iPhone 14 Pro** (Safari & Chrome в полноэкранном режиме «На экран „Домой“» без нижней панели браузера):

- **Сегодня**: сводка дня, быстрый трекинг воды и ближайшей привычки, список задач на день (с переносом и привязкой к целям), лента «Что сделано за день», итог дня и рефлексия, «Итоги года».
- **Привычки и Тело**:
  - **Привычки и витамины** по времени дня (**Утро**, **Обед**, **Вечер**) с дозировками, временем выполнения и сериями + **Трекер воды** (`+200/+250/+500 мл`, отмена, дневная цель).
  - **Тренировки**: Дыхательная практика (с интерактивным дыхательным таймером), Пилатес, Цигун и своя практика, недельная полоса и история за 30 дней.
  - **Женский цикл (12+ месяцев)**: календарь с навигацией на год+ назад, симптомы, настроение, заметки, прогноз менструации/овуляции/фертильного окна и архив циклов.
- **Питание**: рацион дня по приёмам (**Завтрак**, **Обед**, **Ужин**, **Перекус**) с выбором из личного **Меню блюд**, порциями/граммами, временем приёма, КБЖУ и быстрым добавлением в список покупок.
- **Дом**: уборка и бытовые дела по зонам и частоте + быстрый список покупок по категориям.
- **Цели (1–5 лет)**: долгосрочные цели с контролем темпа («В графике» / «Нужно внимание» / «Опережаю план»), вехами по годам/кварталам, регулярными чек-инами и связью с ежедневными привычками.

## Запуск локально

```bash
./run.sh
```

Приложение откроется на `http://127.0.0.1:8098` (порт настраивается через `MARINA_PORT` или `PORT`, путь к SQLite — через `MARINA_DB_PATH`).

Режим разработки (FastAPI `--reload` + Vite dev server с прокси `/api`):

```bash
./run.sh --dev
```

## Сборка и проверки

```bash
# Сборка фронтенда в dist/
npm run build

# API-тесты
uv run pytest -q

# Аудит PWA (манифест, мета-теги iOS, Service Worker, иконки)
uv run python ops/check_pwa.py
```
