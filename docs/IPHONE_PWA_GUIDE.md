# Ритм (Marina Tracker) — Установка на iPhone 14 Pro, локальный запуск и деплой на Render

Приложение **«Ритм»** спроектировано как мобильное PWA под **iPhone 14 Pro (`393 × 852 pt`)** с учётом выреза Dynamic Island (`env(safe-area-inset-top)`), нижней полосы Home Indicator (`env(safe-area-inset-bottom)`), защиты от автозума полей ввода (`font-size: 16px`) и полноэкранного режима без нижней панели браузера (`display: standalone`).

---

## 1. Установка на iPhone 14 Pro (экран «Домой» без панели браузера)

> **Важно:** Для полноэкранной установки с Service Worker и офлайн-кэшем оболочки iOS требует **HTTPS** (например, ваш домен на Render). В локальной Wi-Fi сети по `http://<IP>:8098` ярлык на экран «Домой» также добавляется и открывается без панели браузера, но Service Worker активируется только на `https://` или `localhost`.

### Вариант А — через Safari (рекомендуется)
1. Откройте адрес приложения в **Safari** на iPhone 14 Pro.
2. Нажмите кнопку **«Поделиться»** (квадрат со стрелкой вверх в нижней панели Safari).
3. Прокрутите меню вниз и выберите **«На экран „Домой“»** *(Add to Home Screen)*.
4. Проверьте название **«Ритм»** и фирменную тёмно-зелёную иконку с двумя дугами, затем нажмите **«Добавить»**.
5. Запустите **«Ритм»** с домашнего экрана — приложение откроется на весь экран **без адресной строки и нижней панели Safari**, со встроенной 5-вкладочной нижней навигацией.

### Вариант Б — через Google Chrome (iOS 16.4+)
1. Откройте адрес приложения в **Chrome** на iPhone 14 Pro.
2. Нажмите иконку **«Поделиться»** (справа в адресной строке).
3. Выберите **«На экран „Домой“»** *(Add to Home Screen)* → **«Добавить»**.
4. Запустите установленную иконку **«Ритм»** с домашнего экрана.

> Если пункт «На экран „Домой“» не отображается в Chrome (на старых версиях iOS), откройте ту же ссылку в Safari и выполните шаги из варианта А.

### Как убедиться, что приложение открыто в standalone-режиме
- Нет нижней панели навигации и адресной строки Safari/Chrome.
- Верхняя область вокруг Dynamic Island гармонично сливается со светлым фоном приложения (`#F7F5F0`), а время и индикатор батареи остаются чёткими и тёмными.
- Нижнее меню (`Сегодня`, `Привычки`, `Питание`, `Дом`, `Цели`) закреплено прямо над системной полосой Home Indicator и не перекрывает контент.
- При нажатии на любое поле ввода экран не приближается (отсутствует автозум iOS Safari).

## 2. Локальный запуск (Linux / WSL)

Перед запуском убедитесь, что в `PATH` доступны `uv` и Node 22:

```bash
export PATH="/home/ruslan_safaev/.local/bin:/home/ruslan_safaev/.nvm/versions/node/v22.23.2/bin:$PATH"
```

### Продакшн-режим локально (FastAPI + собранный `dist/`)
```bash
cd /home/ruslan_safaev/marina_tracker
./run.sh
```
По умолчанию сервер стартует на `http://0.0.0.0:8098` (откройте на компьютере `http://127.0.0.1:8098`, а с iPhone в той же Wi-Fi сети — `http://<локальный-IP-компьютера>:8098`).

Полезные переменные окружения:
- `MARINA_PORT=8098` — порт FastAPI-сервера.
- `MARINA_HOST=0.0.0.0` — адрес привязки (для доступа с телефона по локальной сети оставьте `0.0.0.0`, для локальной отладки можно `127.0.0.1`).
- `MARINA_DB_PATH=data/marina_tracker.sqlite3` — путь к SQLite-базе данных.
- `MARINA_REBUILD=1` — принудительно пересобрать фронтенд (`npm run build`) перед стартом.

### Режим разработки (Vite HMR + FastAPI `--reload`)
```bash
./run.sh --dev
```
API поднимается на `:8098`, фронтенд Vite с прокси `/api` — на `:5173`.

## 3. Деплой на Render (HTTPS для iPhone PWA)

Репозиторий готов к деплою на **Render** через `Dockerfile` и `render.yaml`:

1. Загрузите репозиторий на GitHub (ветка `main`).
2. В панели Render выберите **New → Blueprint** и укажите репозиторий — Render автоматически прочитает `render.yaml`:
   - `runtime: docker`, сборка из многоэтапного `Dockerfile` (Node 22 собирает `dist/`, Python 3.12 запускает FastAPI + Uvicorn на `0.0.0.0:$PORT`).
   - `healthCheckPath: /api/health` проверяет готовность сервиса.
   - HTTPS-сертификат выдаётся автоматически — ссылку `https://<your-app>.onrender.com` можно сразу ставить на экран «Домой» iPhone 14 Pro.

### Хранение SQLite-базы на Render
- **Free plan (`plan: free`)**: файловая система контейнера эфемерная — при перезапуске контейнера база пересоздаётся с демо-данными. Для личного постоянного использования подключите **Render Persistent Disk** (доступен с тарифа Starter) с точкой монтирования `/app/data` и оставьте `MARINA_DB_PATH=/app/data/marina_tracker.sqlite3`.
- Все данные (привычки, витамины, вода, тренировки, 12+ месяцев цикла, рацион, задачи, уборка, покупки и многолетние цели) хранятся в одном файле SQLite в режиме WAL (`PRAGMA journal_mode=WAL`).

## 4. Сервисные скрипты `ops/`

### Перегенерация брендовых иконок PWA
```bash
python3 ops/generate_icons.py
```
Генерирует в `public/icons/` чистым Python (без внешних зависимостей):
- `apple-touch-icon.png` (`180×180`, квадратный фон для iOS squircle)
- `icon-192.png` (`192×192`)
- `icon-512.png` (`512×512`)
- `icon-512-maskable.png` (`512×512`, с безопасными полями ≥ 21%)
- `icon.svg` (векторный favicon)

### Автоматический PWA и Ops аудит
Статическая проверка исходников и собранного `dist/`:
```bash
python3 ops/check_pwa.py --static --dist
```

Полная проверка (исходники + `dist/` + живой HTTP-сервер, MIME-типы, заголовки `Service-Worker-Allowed` и `Cache-Control: no-cache`, реальные размеры PNG-иконок и SPA fallback):
```bash
python3 ops/check_pwa.py --static --dist --url http://127.0.0.1:8098
```
